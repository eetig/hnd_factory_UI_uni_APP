# 交互自检清单

> 每次改完交互（抽屉、弹层、列表、手势）在真机上照着过一遍。
> 来源：apple-design（WWDC *Designing Fluid Interfaces*）第 10 节的清单，
> 按本项目的实际交互裁剪过 —— 不是通用清单，是**这个 App 会踩的那几条**。
>
> 为什么写下来：这类检查靠记忆一定会漏，而漏掉的表现往往只是"感觉有点怪"，
> 没人会为此开一个 bug。

## 一、抽屉（从左侧滑出）

- [ ] 按住拖动时**跟手**：手指到哪，抽屉到哪，不滞后、不抖
- [ ] 拖过约 1/3 宽度松手 → **吸附关闭**；没拖过 → 弹回打开
- [ ] **快速甩**（没过 1/3）→ 也关闭（看速度，不只看位移）
- [ ] 拖动**回拉**：甩出去一半又拉回来，抽屉跟着回来，不抢方向
- [ ] 收起动画**播到一半时点一下抽屉** → 从当前位置滑回来（不是等它收完再开）
- [ ] 打开/关闭**各震一下**（轻），纯点按汉堡不震
- [ ] 抽屉里的列表滚到底再上滑，**页面不跟着滚**（overscroll 已被 contain）

## 二、弹层（日期 / 物料选择 / 表单）

- [ ] 出现**没有"两段动画"**：容器滑进来时内容不再单独飞一次
- [ ] 弹层内滚动到底，**底层页面不动**
- [ ] 点遮罩能关；有未保存内容时**先问一句**
- [ ] 弹层里再开一层（日期里开年份、表单里开选择器）→ 内层**不被裁掉**
- [ ] 连续快速开关两次 → 第二次能正常打开（不被"正在关闭"吞掉）

## 三、图片查看器

- [ ] 单指拖动到边界 → **停住**（平台钳制，这是已知取舍，不是 bug）
- [ ] 双指缩放：跟手、不跳、不回到 1×
- [ ] 双击放大 / 再双击还原
- [ ] 长按 450ms → 保存层出现；**按住后手指一动，长按取消**
- [ ] 多指时不会误触发长按
- [ ] 删除有二次确认

## 四、全局

- [ ] 点任意按钮，**按下去就有反馈**（缩放/变色），不等抬手
- [ ] 保存成功 → 轻震 + toast；保存失败 → 重震 + 错误提示
- [ ] 系统开「减少动态效果」→ 所有动效近乎瞬时；**关掉后恢复**
- [ ] 手机静音/无马达的机器上，功能不受影响（触感静默失效）

## 五、改完必须跑的命令

```bash
# 前端（网页端）
npm run verify            # lint + test + build

# APP
npm run build:h5          # 至少跑这个，SCSS 语法错会在这里暴露
```

> ⚠️ **测试通过 ≠ 构建通过**：`vitest` 会放过"具名导出不存在"这类问题，
> `vite build` 不会（rollup 严格校验）。两个都要跑。
> 另：`<style scoped>`（没写 `lang="scss"`）的组件里**不能写 `$ui-*` 变量** ——
> 写了会原样输出到 CSS 里、被浏览器丢弃，表现是"圆角/颜色没生效但不报错"。

## 六、动效数字（全项目一套，改之前先看这里）

| 动作 | 时长 | 曲线 |
|---|---|---|
| 按下反馈 | 100ms | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 弹层入场 / 抽屉关闭 | 220–240ms | 同上 |
| 抽屉打开 | 300ms | 同上 |
| 内容入场 | 160ms / 位移 4px | 同上 |
| 数据到达（数字、条形） | 600–700ms | 同上 |

**判据**：一天点几十次的动作不加动效；只在"数据到达"和"用户主动改变视线焦点"时动。
